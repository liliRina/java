## CarLeasing — система автолизинга
Серия из 7 домашних работ, где каждая посвящена отдельной технологии: от консольного CRUD до Spring микросервисов с RabbitMQ.

***Технологии***

### Функционал:
1. Управление автомобилями: добавление, просмотр, поиск по марке/модели/году, удаление
2. Управление клиентами: регистрация, просмотр, поиск по ФИО/паспорту, удаление
3. Договоры лизинга: создание, расчёт аннуитетных платежей, просмотр истории
4. Платежи: внесение оплаты, закрытие договора

### Описание проектов по каждой домашней работе:
1. Java Core + Jackson -- Консольное приложение на чистой Java с хранением данных в json
2. Многопоточность -- Работа с данными в фоне без блокирования консольного интерфейса, параллельная обработка платежей
3. JDBC + PostgreSQL -- Переход от файлового хранилища к PostgreSQL
4. SLF4J + Logback + JUnit5 -- Добавление юнит-тестов и логирования ввода пользователя и ошибок
