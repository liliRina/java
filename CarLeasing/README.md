## CarLeasing — система автолизинга
Серия из 8 домашних работ, где каждая посвящена отдельным технологиям: от консольного CRUD до Spring сервиса с RabbitMQ.

***Технологии:*** 
1. **Язык и инструменты:** Java Core, Stream API, Lombok, SLF4J, Jackson
2. **Многопоточность:** ExecutorService, BlockingQueue, CopyOnWriteArrayList, AtomicInteger, CompletableFuture
3. **Spring:** Boot/MVC/JPA/Security (JWT)
4. **БД:** PostgreSQL, Hibernate
5. **Брокер сообщений:** RabbitMQ 
6. **Тестирование:** JUnit 5, Mockito

### Функционал:
1. Управление автомобилями: добавление, просмотр, поиск по марке/модели/году, удаление
2. Управление клиентами: регистрация, просмотр, поиск по ФИО/паспорту, удаление
3. Договоры лизинга: создание, расчёт аннуитетных платежей, просмотр истории
4. Платежи: внесение оплаты, просмотр платежей по номеру договора

### Описание проектов по каждой домашней работе:
1. *Java Core + Jackson + Stream API* -- Консольное приложение на чистой Java с хранением данных в JSON. BigDecimal для денег, валидация ввода (VIN, паспорт), ленивая загрузка JSON по разделам меню
2. *Многопоточность* -- Работа с данными в фоне без блокирования консольного интерфейса, параллельная обработка платежей.  ExecutorService, CopyOnWriteArrayList, BlockingQueue. Отмена платежа в памяти при сбое записи в файл
3. *JDBC + PostgreSQL* -- Переход от файлового хранилища к PostgreSQL для машин, клиентов и платежей
4. *SLF4J + Logback + JUnit5 + Mockito* -- Добавление юнит- и интеграционных тестов и логирования ввода пользователя и ошибок.
5. *Spring Boot + JDBC + Validation* -- Переход в REST-сервис. Управление приложением через эндпоинты, добавлены транзакции и глобальная обработка ошибок в контроллерах
6. *Hibernate* -- Внедрение сущностей. @ManyToOne связь для контрактов - машин и контрактов - клиентов, составной первичный ключ для платежей, двойное хранение договоров (БД + файлы) с приоритетом БД
7. *Spring Security + JWT* -- Доступ к эндпоинтам разграничен по ролям админ/пользователь через @PreAuthorize и SecurityFilterChain. Также публичные эндпоинты для неаутентифицированных запросов. PasswordEncoder, отдельный контроллер для регистрации и входа, сохранение ролей в БД
8. *RabbitMQ* -- Асинхронная обработка запросов через брокер сообщений. Отправка сообщений в сервисах и получение - в добавленных классах-слушателях. Работа с бд производится в классах-слушателях. Обработка мёртвых сообщений
